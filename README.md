DOCKLIGHT — a top-down stealth game in a night-shift container dockyard. You are the courier: lift 3 intel crates on each of 3 yards, then reach the moored boat unseen. Guards patrol fixed routes with vision cones that react (patrol → suspicious "?" → alert "!" → search → recover); containers block sight and movement; sneaking is slow and quiet, running is fast and loud; sweeping searchlights fill an exposure meter; footsteps pan and fade with distance so you can hear where a guard is. Canvas 2D, all art drawn in code, all sound synthesised with WebAudio — no external assets, no network.

## Run it

```sh
python3 -m http.server 8080 --directory game
# open http://localhost:8080
```

WASD / arrows move · SHIFT sneak · E grab intel · R restart · ESC menu. `?shot=title|cover|alarm|complete|win` stages a moment for screenshots.
